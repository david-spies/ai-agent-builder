## Overview

Ai-Agent Builder produces a package of `.md` configuration files. This guide covers how to deploy those files to each supported platform and environment.

There are two things to deploy:
1. **The Builder** — `ai-agent-builder.html` (the authoring tool itself)
2. **The Agent Package** — the `.md` files generated by the builder

---

## Part 1: Deploying the Builder (ai-agent-builder.html)

The builder is a single HTML file. It runs from `file://` or any static host with zero configuration.

### Local (file:// — simplest)
```bash
# Just open the file
open ai-agent-builder.html          # macOS
xdg-open ai-agent-builder.html      # Linux
start ai-agent-builder.html         # Windows PowerShell
```

### Local Dev Server (recommended for teams)
```bash
# Python (no install required)
python3 -m http.server 3000
# → http://localhost:3000/ai-agent-builder.html

# Node.js (via npx, no install)
npx serve . --port 3000
# → http://localhost:3000/ai-agent-builder.html

# Deno
deno run --allow-net --allow-read https://deno.land/std/http/file_server.ts
```

### GitHub Pages (free, public)
```bash
# Method 1: Put file in repo root, enable Pages
# Settings → Pages → Branch: main → Folder: / (root)
# Access at: https://your-org.github.io/ai-agent-builder/ai-agent-builder.html

# Method 2: Deploy directly to gh-pages branch
git checkout --orphan gh-pages
git add ai-agent-builder.html
git commit -m "deploy: ai-agent-builder v1.0.0"
git push origin gh-pages
```

### Netlify (one-click)
```bash

# Go to netlify.com/drop and drag the HTML file

npm install -g netlify-cli
```

### Vercel

## Part 2: Deploying the Agent Package

The agent package is the set of `.md` files downloaded after clicking "Build Agent."

### Package Contents

After a build, you receive (downloaded to your machine):
```
{agent-slug}-SKILL.md
{agent-slug}-AGENTS.md
{agent-slug}-guardrails.md
{agent-slug}-llm-judge.md
{agent-slug}-audit-trails.md
{agent-slug}-README.md
```

Rename and reorganize to the standard structure before deploying:

```bash
# Create standard structure
mkdir -p my-agent/{.agents/skills,references,agents/{architect,worker,security}}

mv {agent-slug}-SKILL.md       my-agent/SKILL.md
mv {agent-slug}-AGENTS.md      my-agent/AGENTS.md
mv {agent-slug}-guardrails.md  my-agent/references/guardrails.md
mv {agent-slug}-llm-judge.md   my-agent/references/llm-judge.md
mv {agent-slug}-audit-trails.md my-agent/references/audit-trails.md
mv {agent-slug}-README.md      my-agent/README.md

# Validate
bash my-agent/scripts/validate.sh my-agent/
```

## Platform-Specific Deployment

### Claude Code

Claude Code automatically discovers skill files from two locations:

| Location | Scope |
|---|---|
| `~/.claude/skills/` | Personal — available in all your projects |
| `.claude/skills/` | Project — shared with team via git |

```bash
# Personal skill (available everywhere)
mkdir -p ~/.claude/skills/my-agent/
cp my-agent/SKILL.md ~/.claude/skills/my-agent/
cp -r my-agent/references/ ~/.claude/skills/my-agent/

# Project skill (check into git)
mkdir -p .claude/skills/my-agent/
cp my-agent/SKILL.md .claude/skills/my-agent/
cp -r my-agent/references/ .claude/skills/my-agent/
git add .claude/skills/
git commit -m "feat: add my-agent skill"
```

**Verification**: In Claude Code, ask:
```
What skills do you have available?
```
If the skill appears, activation is working.

### API Integration (Direct)

Use the SKILL.md as a system prompt with any Anthropic-compatible API:

```python
import anthropic
from pathlib import Path

client = anthropic.Anthropic()

def load_skill(skill_path: str) -> str:
    """Load SKILL.md and its references into a system prompt."""
    skill_content = Path(skill_path).read_text()

    # Extract referenced files and append them
    import re
    refs = re.findall(r'- (\.\/references\/\S+\.md)', skill_content)
    ref_contents = []
    skill_dir = Path(skill_path).parent

    for ref in refs:
        ref_path = skill_dir / ref.replace('./', '')
        if ref_path.exists():
            ref_contents.append(f"\n\n---\n## {ref_path.name}\n{ref_path.read_text()}")

    return skill_content + "".join(ref_contents)


def run_agent(user_request: str, skill_path: str) -> str:
    system_prompt = load_skill(skill_path)

    response = client.messages.create(
        model="claude-sonnet-4-20250514",
        max_tokens=4096,
        system=system_prompt,
        messages=[{"role": "user", "content": user_request}]
    )
    return response.content[0].text


# Usage
result = run_agent(
    "Review this Python file for security issues: [paste code]",
    "./my-agent/SKILL.md"
)
print(result)
```

### LangGraph Workflow

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated
import operator

class AgentState(TypedDict):
    messages: Annotated[list, operator.add]
    skill_content: str
    current_step: str
    eval_result: dict | None
    revision_count: int

def load_skill_node(state: AgentState) -> AgentState:
    skill = Path("my-agent/SKILL.md").read_text()
    return {"skill_content": skill, "current_step": "planning"}

def planning_node(state: AgentState) -> AgentState:
    # Uses Architect agent logic
    return {"current_step": "execution"}

def execution_node(state: AgentState) -> AgentState:
    # Uses Developer Worker logic with skill as system prompt
    return {"current_step": "evaluation"}

def evaluation_node(state: AgentState) -> AgentState:
    # Uses LLM Judge from references/llm-judge.md
    eval_result = run_judge(state)
    return {"eval_result": eval_result}

def route_after_eval(state: AgentState) -> str:
    if state["eval_result"]["verdict"] == "Pass":
        return "guardrails"
    if state["revision_count"] >= 2:
        return "hitl_gate"
    return "execution"  # retry

def guardrails_node(state: AgentState) -> AgentState:
    # Apply guardrails from references/guardrails.md
    return {"current_step": "complete"}

# Build graph
workflow = StateGraph(AgentState)
workflow.add_node("load_skill", load_skill_node)
workflow.add_node("planning", planning_node)
workflow.add_node("execution", execution_node)
workflow.add_node("evaluation", evaluation_node)
workflow.add_node("guardrails", guardrails_node)

workflow.set_entry_point("load_skill")
workflow.add_edge("load_skill", "planning")
workflow.add_edge("planning", "execution")
workflow.add_edge("execution", "evaluation")
workflow.add_conditional_edges("evaluation", route_after_eval)
workflow.add_edge("guardrails", END)

app = workflow.compile()
```

### CrewAI

```python
from crewai import Agent, Task, Crew
from pathlib import Path

skill_content = Path("my-agent/SKILL.md").read_text()

# Parse agent roles from AGENTS.md
architect = Agent(
    role="Architect",
    goal="Decompose requirements into build plans",
    backstory="Senior AI systems architect with 10 years designing production agents",
    verbose=True,
    allow_delegation=True
)

worker = Agent(
    role="Developer Worker",
    goal="Generate all agent configuration files",
    backstory="Senior full-stack engineer specializing in AI configuration",
    verbose=True,
    allow_delegation=False
)

security_officer = Agent(
    role="Security Officer",
    goal="Find every reason the generated files should NOT ship",
    backstory="Cynical CISO with zero tolerance for security debt",
    verbose=True,
    allow_delegation=False
)

# Tasks
plan_task = Task(
    description="Analyze the user request and produce a structured build plan",
    expected_output="JSON build plan with file list, generation order, scope",
    agent=architect
)

generate_task = Task(
    description=f"Generate all agent files per the build plan. Follow this skill protocol:\n{skill_content}",
    expected_output="Complete set of .md files",
    agent=worker
)

security_task = Task(
    description="Review all generated files. Find every CRITICAL and HIGH security finding.",
    expected_output="Security review JSON with verdict and findings",
    agent=security_officer
)

crew = Crew(
    agents=[architect, worker, security_officer],
    tasks=[plan_task, generate_task, security_task],
    verbose=True
)

result = crew.kickoff()
```

## Environment Setup

### Required Environment Variables

```bash
# Create .env file (never commit this)
cat > .env << 'EOF'
# LLM Provider (choose one)
ANTHROPIC_API_KEY=sk-ant-...
# OPENAI_API_KEY=sk-...
# GOOGLE_API_KEY=...

# Workspace
WORKSPACE_ROOT=/absolute/path/to/your/workspace

# Audit logging
AUDIT_LOG_PATH=./logs/audit.jsonl
AUDIT_LOG_ENDPOINT=https://your-siem.example.com/events  # optional

# HITL notifications (optional)
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...

# Secrets management (required for elevated scope)
VAULT_ADDR=https://vault.your-org.com
VAULT_TOKEN=hvs....

# Cost tracking (optional)
DATADOG_API_KEY=...
EOF

# Load for current session
export $(cat .env | xargs)

# Validate
python -c "import anthropic; print('API key valid')" 2>/dev/null || echo "Check ANTHROPIC_API_KEY"
```

### Verify Deployment

```bash
# Run package validator
bash scripts/validate.sh . --strict

# Run eval suite
python scripts/eval-runner.py \
  --golden-set evals/golden-set/ \
  --threshold 4.0 \
```
