## Error Levels L0 TRANSIENT → retry 1-2x immediately L1 RETRYABLE → exponential backoff (3s→9s→27s) L2 SKILL_FAIL → invoke fallback_skill chain L3 DEGRADED → switch to degraded mode L4 FATAL → halt · alert · return partial ## Circuit Breaker CLOSED → (5 failures) → OPEN OPEN → (30s probe) → HALF-OPEN HALF-OPEN → (2 ok) → CLOSED ## Fallback Chains rag-retrieval → reasoning-only → gate security-audit → llm-only → gate code-review → basic-lint-only
